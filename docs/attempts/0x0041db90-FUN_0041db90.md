## What still differs

- `volatile float x` is NOT what the original does: it keeps x on the FPU stack
  (`fld [esi]; fld st0; fmul st1; faddp st2; fstp st0`). The real difference is the frame: the original
  has one more slot (0x6c vs 0x68) because `savedval` gets its own slot, while ours packs it into obj's
  parameter slot. Ours can because it keeps obj in a register; the original reloads obj from its
  parameter slot inside the loop (`mov edx, [esp+0x84]` for the `node != &obj->head` test), and keeps
  `node` in ebx. volatile x only happens to add the missing slot. Find the source shape that keeps obj in
  memory, then drop the volatile.
