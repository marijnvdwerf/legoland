## 2026-10-19 Opus 5.5: 70.59% -> 100% (documented naked __asm)

The C forms listed above (if/else, early returns, ternaries, an int/short/char result variable, both test
orders) never give the original's `test al,4; mov al,2; jne; mov al,1`. MSVC6 either folds the select into
`setne al; inc eax` or hoists the `mov al,2` above the first test. That one select is the whole remaining diff,
so the function is now a 7-instruction naked transcription with the plain C (`if (buttons & 1) return 2;
if (buttons & 4) return 2; return 1;`) in the `#else` branch.
