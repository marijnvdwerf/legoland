## What still differs
The original emits the `return 3` for `case 1` of the submode switch as its own block (0x4092d9), separate from the
`dx > 0` return 3 block (0x409327). Our build merges them, so the jump table entry for case 1 points at the dx>0 block,
and every later jump offset shifts by 9 bytes. Case 3 (return 7) is shared with the `dx < 0` block in both builds.
